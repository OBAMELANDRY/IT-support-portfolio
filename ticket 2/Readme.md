# INC9314274 – Email rejecting new password

**Platform:** SysDesks (helpdesk simulator)
**Category:** Software > Email | **Priority:** P4 Low | **Level:** Service Desk Level 1

## Reported Issue
Tyler Brooks (Facilities Coordination) changed his password following the
company reminder. His email application subsequently indicated that the
password was incorrect. He requested a reset.

## Diagnostic Steps
1. Thorough review of the ticket, including communications from the requester.
2. Finding: the issue stemmed from the email app on his phone,
   which was still using the old password.
3. Decision **not to reset the password**: the account
   was functioning correctly; a reset would have been unnecessary and risky.
4. Contacted the user via chat to confirm everything was working.

## Cause
The phone's email app had retained the old password.
The account itself was not the issue.

## Resolution
- No changes made to the account.
- User confirmed that email was working.
- Advice: update the password on all devices.
- Ticket closed with the code "Resolved (Permanently)."

## Demonstrated Skills
Careful ticket reading, avoiding unnecessary actions, customer
communication, verification before closure, preventive advice, documentation.
